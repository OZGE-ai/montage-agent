# Правила монтажа: откуда они взялись

Каждое правило — это реальное замечание заказчика к очередной версии интервью, переведённое агентом в проверяемое условие.

| Версия | Замечание заказчика (близко к тексту) | Правило агента | Где в коде |
|---|---|---|---|
| v1 → v2 | «Удалить по всему ролику паузы, аа, ммм, эээ» | Паузы > 0,4 с → ~0,25 с; ровный голос ≥ 0,3 с (запинка) → 0,2 с | `edit.py`, `hesitations.py` |
| v1 → v2 | «Неправильные повторения тоже нужно удалить» | Агент читает дословную расшифровку и помечает повторы и оговорки; скрипт проверяет текст на каждом стыке | `project.json → edits`, `edit.py` |
| v1 → v2 | «Камеру определяй по взгляду спикера, он должен смотреть в кадр, а не мимо» | Поворот головы + зрачки на всех камерах (MediaPipe) | `gaze.py` |
| v1 → v2 | «Перебивка должна быть динамичной, с музыкой; заставка — не на чёрном, а на видео мероприятия» | Короткие переходы между фразами, заставка поверх видео, күй ансамбля с саммита | `graphics.py`, `render.py` |
| v2 → v3 | «Начни с фразы с цифрой, потом — фраза-конфликт» | Порядок фраз задаётся в `triggers_order` | `project.json` |
| v2 → v3 | «Когда я представляю спикера, я говорю в центральную камеру — вступление с центральной камеры» | Вступление ведущей целиком на общем плане | `shots.py` |
| v2 → v3 | «Корпе на кадре — только на общем плане; спикеров — крупно, без корпе» | Средние планы из общей камеры запрещены; крупный ведущей кадрируется без декора | `shots.py`, `CROP["C"]` |
| v2 → v3 | «Конец не должен быть чёрным — синий фон, строка хаба и Ozge media» | Растворение в синий, логотипы | `graphics.py → render_outro` |
| v3 → v4 | «Музыку возьми из записи экрана; между фразами — чух-чух, не чёрная вставка» | Переход «зум» + синтезированный звук перехода, музыка заказчика | `render.py`, `sfx.py` |
| v3 → v4 | «Когда я читаю вопросы, мои глаза не должны попадать в общий кадр — я всегда слушаю гостя» | Общий план запрещён, если ведущая читает (раскрытие век < 0,30) > 10 % времени плана | `gaze.py eyes`, `shots.py → reading_frac` |
| v3 → v4 | «Резкие переходы близко–далеко так не должно быть, всё плавно» | Нет приближений; все склейки — растворение 0,2–0,3 с; общий план реже | `render.py` |
| v3 → v4 | «В конце говорит спикер, а в кадре стоит ведущая» | Крупный план не переходит через смену говорящего; проверка в отчёте | `shots.py` |
| v3 → v4 | «Строка хаба крупнее, Ozge media меньше, сверху логотип хаба» | Раскладка финала | `graphics.py` |

## Проверки, которые `shots.py` печатает после каждой сборки

- крупный план не того, кто говорит, дольше 1 с — должно быть пусто;
- общие планы, где ведущая читает больше 15 % времени — должно быть пусто;
- длительность планов: минимум, медиана, максимум;
- число смен камеры и склеек внутри планов.
